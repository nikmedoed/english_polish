# Глагольные модели

**Критичность: 82/99.** Средне-высокая; prep + -ing пока дополнительная гипотеза.

## Основание приоритета

Исходный обзор: 6 примеров-кандидатов в 4 сессиях. Это выбранные сигналы, не полный подсчёт ошибок. Срез корпуса: февраль — октябрь 2026, 22 записи. Личные записи и исходные цитаты хранятся только в приватном архиве.

## Обезличенные учебные иллюстрации

Примеры ниже написаны для объяснения паттерна и не являются цитатами из разговоров.

| Ошибочная модель | Целевая форма | Почему |
|---|---|---|
| `You should to take a break.` | `You should take a break.` | После should — начальная форма без to. |
| `They decided leaving early.` | `They decided to leave early.` | Decide + to + V. |
| `She is interested in learn languages.` | `She is interested in learning languages.` | После предлога in — -ing. |

## Что тренировать

Can/should/might/must + V без to; decide/need/want/promise + to V; enjoy/avoid/suggest/recommend + -ing; advise someone to V; после предлога — -ing. Remember/stop/try меняют смысл с to/-ing; be used to + -ing. Не использовать глаголы с несколькими допустимыми моделями как однозначные карточки без контекста.

## Что измерять

Точность самостоятельного воспроизведения на разных примерах; отложенная проверка в другой день; перенос в собственную короткую речь. Самооценку устного ответа учитывать отдельно. Для речи из транскрибаций считать подтверждённые ошибки на проверенные возможности употребления конструкции; без знаменателя частоту не заявлять.
